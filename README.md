# Summa

Summa explores an AI assistant built from two parts: knowledge and intelligence.

## Knowledge

The assistant's knowledge can come from:

- persisted statements;
- deterministic tools;
- additional knowledge models explored by the project.

## Intelligence

The assistant's intelligence comes from an integrated large language model that works with the available knowledge.

## Development status

Summa is in an early experimental stage. Development proceeds through small spikes. Current areas of investigation are recorded in [proposed-spikes.yaml](proposed-spikes.yaml).

## Contributing

1. Fork the repository.
2. Create a branch in your fork.
3. Make your changes. You may propose a new spike, implement an existing spike, or include a proposal and its implementation together.
4. Follow [proposed-spikes.template.yaml](proposed-spikes.template.yaml) when adding a proposal.
5. Submit a pull request describing your changes and how they were verified.
